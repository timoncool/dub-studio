# Непрерывная диаризация с заданным числом участников

## Причина

Живой прогон записи после 03:00 остановился на третьем часовом фрагменте: локальная метка внутри фрагмента содержит образцы разных участников, поэтому усреднённые признаки не дают допустимого совместного сопоставления. Снижение порогов или принудительное назначение меток не разрешены.

Непрерывный проход той же Nemotron 3 Diarization на всей подготовленной записи завершился с восемью голосами. Независимая проверка WeSpeaker по трём чистым образцам каждого голоса в каждом часе показала, что все 40 сравнений с первым часом выбирают свою метку. Результат диагностического прохода не подменяет завершение задания студии.

## Изменение

Добавить явно включаемый оператором режим `DUB_STUDIO_DIAR_CONTINUOUS=1` для диаризации с заданным числом участников. Сохранять непрерывное состояние модели на всей дорожке, разделять кэш непрерывного и прежнего режимов и явно сообщать выбранный режим. По умолчанию поведение сохраняется; пользовательские настройки и проекты не изменяются.

Режим требует памяти для всей дорожки. На рабочем компьютере 64 ГБ RAM; модели, движки и квантизации сохраняются. Дополнение публикуется в ветке `fix/expected-speaker-count` существующего PR №13 после повторной проверки исходников.
