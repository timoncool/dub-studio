# Решение

Переменная окружения процесса принимает только `0` или `1`; отсутствие означает прежний режим. Неверное значение сообщает ошибку. При числе участников 0 или 1 она не влияет на анализ.

Для числа 2–8 непрерывный режим выбирает единственное окно `[0, duration]`; Sortformer работает с прежним offline streaming profile, WeSpeaker остаётся проверкой голосовых образцов. Существующее ограничение заданного числа и проверка признаков не ослабляются. В обычном режиме сохраняется прежний план часовых окон и перекрытий.

Ключ стадии использует отдельную версию `known-voices-continuous-v1`. Отпечаток диаризации уже включён в ключ распознавания, поэтому смена режима не переиспользует чужую разметку. Прогресс называет непрерывный режим явно. При перезапуске для возобновления сохраняется та же переменная окружения процесса.

Экспериментальные варианты с короткими окнами и временными якорями в рабочий код не переносятся. Исправление больших WAV не входит в эту правку: промежуточные дорожки текущего отдельного проекта восстановлены в PCM16 с проверкой полной длительности.
