# Анализ: сжатие тишины

## Требования

### Параметр

Пользователь и агент включают сжатие тишины параметром анализа. По умолчанию выключено; выключенный параметр
не меняет поведение, ключи кэша и результаты старых проектов. Значение переживает возобновление задания.
`transcribe_file` с разным значением параметра даёт разные проекты.

### Сжатие

Пауза тише −60 дБ длиннее 20 с сжимается до 20 с: 10 с после звука и 10 с перед звуком. Звук и запас вокруг него
не вырезаются. Если вырезать можно меньше 60 с или анализ импортирует субтитры, сжатие не применяется и прогресс
сообщает причину.

### Исходное время

Начало и конец каждой реплики и каждого слова в сохранённом проекте — на шкале исходной записи: реплика,
распознанная в сжатой записи, совпадает по времени с той же речью в исходной (допуск 0,1 с, без учёта
неточности самого распознавателя). Слова внутри реплики идут по неубыванию времени. Файлы, которые читают рендер,
кастинг и выравнивание по речи, имеют длину исходной записи; общая папка разделённых дорожек не содержит сжатых файлов.

### Паузы

Паузы исходной записи длиннее 60 с сохраняются в проекте. Текстовая выдача `transcribe_file` показывает их строкой
`— пауза N мин —` между репликами.
